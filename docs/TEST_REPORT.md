Что искать в логе при первом подключении (закрывает открытые вопросы из `docs/REVERSE_ENGINEERING.md`, раздел 7):
- строки `service=… char=… props=… descriptors=…`: есть ли у `FFE1` дескриптор `2902` и флаг NOTIFY;
- `CCCD write started=…` или предупреждение `FFE1 has no CCCD`;
- `notify FFE1 <байты>`: какие байты приходят на одиночное, двойное и долгое нажатие.

### Подтверждено на железе (2026-11-22, POCO 22071219CG, Android 14, брелок «iTAG» D4:80:30:XX:XX:XX)

- Сервисы брелока: `FFE0` (`FFE1` props=NOTIFY|READ с CCCD, `FFE2` write, `FFE3`…`FFE7`), `1802` Immediate Alert (`2A06` write), `1803` Link Loss (тоже `2A06`), `180F` Battery.
- `2A06` присутствует в двух сервисах; для сигнала на брелоке нужен `1802`. Исправлено в коде (в первой версии выбирался `1803`).
- Нажатие кнопки: пакет `FFE1 = 01`. Одиночное нажатие даёт один пакет, двойное два пакета с интервалом около 90–260 мс (по четырём замерам). Формат других жестов не проверялся.
- Запись CCCD выполняется успешно (`CCCD write started=true`). Приходят ли уведомления без неё, не проверялось.
- Итог: пройдены 1, 3, 4, 5, 7, 8. Пропущен 6. Сценарий 2 отдельно не выполнялся.
- Первое подключение с `autoConnect=true` заняло 33 с, с `autoConnect=false` 2,5 с (по одному замеру). Сейчас в коде `autoConnect=false`. Поведение при выходе из зоны и возврате (сценарий 6) с таким режимом ещё не проверено.
- Сценарий 2 (свёрнуто) отдельно не выполнялся: сценарии 3 и 4 покрывают его.

## 3. Ограничения

Известные и не устранённые:
1. **Принудительная остановка** (Настройки, Приложения, Остановить): Android до следующего запуска приложения пользователем не выполняет ни службу, ни `BootReceiver`. Это поведение системы, обход не требуется. Ожидается, что после force-stop нужно открыть приложение один раз.
2. **Xiaomi/POCO (HyperOS)**: агрессивное управление фоном. Нужны «Автозапуск» и «Без ограничений» по батарее, иначе служба может быть остановлена. Не проверено на устройстве.
3. **Протокол выведен статически.** Не подтверждено, что брелок присылает уведомления без записи CCCD и какие байты приходят на другие жесты. Реализация пишет CCCD, если дескриптор есть.
4. **Запуск после перезагрузки.** Android 14 разрешает запускать foreground-службу `connectedDevice` из `BOOT_COMPLETED`, но это не проверено. До первой разблокировки после загрузки поведение зависит от прошивки.
5. **Звук.** Используется системный сигнал будильника на потоке `STREAM_ALARM`. Режим «Не беспокоить» без разрешения будильников может его заглушить. Если системного звука нет, берётся рингтон.
6. **Один брелок.** Нет списка устройств.
7. **Сигнал не прекращается сам.** Звучит, пока его не остановят.
8. **Запись 2A06** (сигнал на брелоке) реализована по оригиналу, на железе не проверена.
9. Оригинальное приложение нужно закрыть или удалить: брелок держит одно соединение.
10. Debug-сборка подписана отладочным ключом, иконки приложения нет.
